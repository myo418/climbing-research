# キャンパシング

関連: [クライミングと怪我](/training/climbing-and-injury/) / [用語集: キャンパスボード](/basics/glossary/campus-board/) / [ヴォルフガング・ギュリッヒ](/climbers/famous/wolfgang-gullich/)

足を使わずに腕だけでボードを登り降りするトレーニング。等間隔に並んだ細い桟（さん）を手で掴んで移動するので、体重のほぼ全部が指と腕にかかる。

## 成り立ち

考案したのはドイツのヴォルフガング・ギュリッヒ。1988年、ニュルンベルクのジム「Campus Centre」で、当時まだ誰も登っていなかったルートのために作った。そのルートが1991年に完登した Action Directe で、ポケットを指だけで引きつけて跳ぶ動きが連続する。器具の名前は、作った場所のジム名がそのまま残ったもの。

## 何が鍛えられるか

ホールドに触れた瞬間に力を立ち上げる速さ——[保持力](/basics/glossary/contact-strength/)のうち、立ち上がりの部分を鍛える。持ったまま耐える力ではなく、飛びついた先で止まる力に効く。

もうひとつは引きつけの出力そのもの。足で支えられないぶん、腕が体を一段上まで持ち上げる必要がある。デッドポイントで止まりきれない、あと一手が遠い、といった場面に直接つながる。

逆に、キャンパシングで持久力は伸びない。1セットが数秒で終わり、間に長い休憩を挟む形になるので、[サーキットトレーニング](/training/circuit-training/)とは目的が違う。

## 基本の動作

| 動作 | やり方 |
|---|---|
| ラダー | 1段ずつ交互に手を上げて登る。降りるときも桟を掴んで下りる |
| 飛ばし（1-3-5 など） | 段を飛ばして上がる。番号は掴む桟の位置 |
| ダブルダイノ | 両手を同時に離して上の段を取る。最も負荷が高い |
| タッチ | 上の段に触れて元の段に戻る。移動距離を伸ばさずに反応だけを鍛える |

段の深さは 2〜3cm 程度のものが標準で、浅いほど負荷が上がる。深い段から始めて、こなせるようになってから浅くする。

## 負荷の高さ

足を使わない以上、指と肘への負荷は通常の登りより明確に大きい。特に危ないのは次の3つ。

- **指の腱鞘（プーリー）** — 飛びついた先で指が急に伸ばされる瞬間に切れる
- **肘の内側（上腕骨内側上顆）** — 引きつけを繰り返すことで慢性的に痛む
- **肩** — 片手でぶら下がった状態から反動をつけるときに抜ける

このため、始める目安は「クライミング歴2〜3年以上」「指の故障がない状態」とされることが多い。始めたばかりの時期は、腱や腱鞘が筋力の伸びに追いつかないまま負荷だけがかかる。

やる場合も、十分にアップした後の、疲れていない状態で行う。登った後の追い込みとして最後にやるのは、フォームが崩れた状態で最大負荷をかけることになるので逆。
