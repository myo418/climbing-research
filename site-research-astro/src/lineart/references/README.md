# 参考画像

描きぶりの基準にする線画をここに置く。**プロンプトを作るとき、ここのファイル名が読み手に渡る**
（`scripts/lineart.mjs prompt` が一覧を埋め込む）。描く前に必ず実物を見る。

置くときの約束:

- ファイル名を `<何の絵か>-<どこが参考か>.<拡張子>` にする（例 `bike-構造線の密度.png`）
- 出典が分かるものは同名の `.txt` にURLを書いておく
- 権利物なので**サイトには出さない**。ここは描き手が見るためだけの場所（`public/` に置かない）

## いま置いてあるもの（2026-09-22）

| ファイル | 何を見るか |
|---|---|
| `motorcycle-機械の構造線.jpg` | 機械を省略せず引く。フォーク・ディスク・スポーク・ケーブルまで全部 |
| `legpress-人とマシンの描き分け.png` | 人は服のしわ数本、マシンは構造線を全部。同じ絵の中で密度を変える |
| `grinder-部位の引き出し線.png` | 部位の名前を引き出し線で付ける図解。線は細く均一 |
| `orchid-花弁の抑揚.jpg` | 有機的な形。輪郭の太さの抑揚だけで厚みと反りを出す |
| `umbrella-girl-線の密度.jpg` | 線を重ねて密度を作る。布のしわの追い方 |
| `travelers-簡略人物とアクセント1色.jpg` | 人物を簡略化したとき、どこまで省いて成立するか。差し色は1色だけ |
| `explainer-説明カットの人物.png` | 説明カットの人物の芝居。表情・吹き出し・手の向き |

ここから読み取った基準:

- **線だけ・塗りなし・陰影なし**。トーンやハッチングで面を作らない
- **人体は「形は正確に、線は少なく」**。比率は実物どおりに取りつつ、引く線は輪郭と形の変わり目だけ。
  しわ・筋・布のたるみ・質感の線は引かない
- **道具・人工物は逆に構造を省かない**。部品・稜線・厚み・縫い目・可動部まで、きれいな線で全部引く
  （`legpress-人とマシンの描き分け.png` と `motorcycle-機械の構造線.jpg` がこの基準そのもの）
- **線は正確**。ガタつかせない。手の揺れは出力時にごく薄く乗るだけ
- **太さは抑揚として使う**。外形はやや太く、内部の構造線は細く本数で見せる
- **同じ絵の中で密度を変えてよい**。見せたいものだけ線を足し、それ以外は輪郭で止める
- **顔のパーツは描かない**。目・眉・鼻・口を入れず、表情を作らない（参考画像の人物には表情があるが、そこは真似しない）
- 点（しべ・ボルト・穴）だけは小さく塗ってよい
- 差し色を使うなら1色だけ（うちの場合は `--color-injury` の暗赤）
