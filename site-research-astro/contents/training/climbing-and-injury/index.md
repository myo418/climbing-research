# クライミングと怪我

クライミングにおける**怪我**を 2 軸で整理する。**どんな怪我をするのか**（部位別・種類別のカタログ）と、**どういう経緯で怪我をするのか**（発生要因・状況・引き金）。

なぜ怪我のリスクを受け入れてまで続けるのか、という**動機・心理**はここでは扱わない（別の場所で掘る）。ここは事実を積む場所。

---

## 1. どんな怪我をするのか（部位別カタログ）

### 指・手
- プーリー（A2 / A4）損傷・断裂
- 屈筋腱腱鞘炎
- 指皮の剥離・割れ
- 関節包損傷（PIP / DIP）
- TFCC損傷（手首）

### 肘
- クライマーズエルボー（内側上顆炎）
- テニス肘（外側上顆炎）
- 肘関節の動作痛

### 肩
- インピンジメント症候群
- ローテーターカフ損傷
- SLAP損傷（関節唇）
- 脱臼

### 腰・背中
- 腰椎ヘルニア
- 筋筋膜性腰痛
- 着地衝撃による腰椎圧迫骨折

### 膝・足首
- 足首捻挫（マット端への着地など）
- 半月板損傷
- アキレス腱炎
- シューズ長期使用による足指の変形

### 頭部・その他
- 墜落時の頭部外傷（ヘルメット無しの外岩で重大化）
- 落石による打撲・裂傷
- 指切断など（カラビナ・ロープ事故）

### 慢性的な変化
- 指関節の肥大
- 指の感覚鈍麻
- 姿勢の歪み（クライマー特有の前肩）

## 2. どういう経緯で怪我をするのか（発生要因）

### 2-1. オーバーユース（蓄積型）
- 高強度セッションを休息不足で繰り返す
- ハングボード・キャンパスの負荷設計ミス
- グレード更新圧で無理な頻度
- 身体の警告サインを無視（違和感を"登れば治る"で押し切る）

### 2-2. 急性外傷（瞬間型）
- **落下・墜落**
  - ボルダー: マット外・マット間への着地
  - リード: グランドフォール、振られ落ち、下のクリップ抜け
- **ホールド破損**
- **スリップ**
- **動的ムーブ失敗**（ランジ、デッドポイントで着地姿勢を崩す）
- **指一本に全荷重**（ポケット、片手ダイノ）

### 2-3. 技術・判断の要因
- ビレイヤーのミス（流した、吸収しきれず衝突）
- ロープワーク不備（ノット、システム）
- ギアセット不良（プロテクション、トップロープ）
- 力量に合わないルート選択
- 準備運動・ウォームアップ不足

### 2-4. 環境・コンディション要因
- 湿った岩、低温で皮膚が割れる
- 岩質の見誤り（脆い岩）
- マットの劣化・不適切な配置
- 登攀時間の読み違い（日没、気象変化）

### 2-5. 長期・構造的要因
- 加齢による組織弾性の低下
- 過去怪我の未治癒で代償動作→別部位に負担
- 体重管理の偏り（減量で骨密度・筋量低下）

---

## 3. 分類の軸（整理用）

- **重症度**: 軽度（登れば治る）／中度（数週〜数ヶ月離脱）／重度（手術・キャリア左右）
- **発生時間**: 急性／慢性
- **責任の所在**: 自責（判断・負荷管理）／他責（ビレイ・ホールド破損）／不可抗力
- **復帰可能性**: 完全復帰／条件付き復帰／引退

→ この軸で図解できる。`diagrams/` に候補メモ。

### Musculoskeletal injuries in rock climbing: a scoping review（2025年）

*BMJ Open Sport & Exercise Medicine*, Vol.12 No.1  
<https://bmjopensem.bmj.com/content/12/1/e002830>

**概要**  
ロッククライミングにおける筋骨格系怪我の有病率・特性を体系的に整理したスコーピングレビュー。45本の研究を対象とし、様々なスキルレベル・年齢層のクライマーを網羅。

**対象研究の内訳**

| 項目 | 数値 |
|---|---|
| 対象論文数 | 45本（1990〜2025年） |
| 急性怪我のみ扱う研究 | 14/45（31.1%） |
| 慢性怪我のみ | 4/45（8.9%） |
| 急性・慢性両方 | 26/45（57.8%） |
| 横断研究 | 33/45（73.3%） |
| 医師による確定診断あり | 15/45、残り30は自己報告のみ |
| 地域：ヨーロッパ | 17/45（37.8%） |
| 地域：北米 | 14/45（31.3%） |
| 室内のみ | 9/45（20%）|
| 屋外のみ | 3/45（6.7%）|
| 両方 | 23/45（51.5%） |

**怪我の部位・診断**

- 最多：**靭帯捻挫**と**筋・腱の損傷**（急性・慢性ともに）
- 上肢では**指・手のプーリー損傷**が最多（6本の研究で上位）
- 下肢では**足首捻挫**が最多。ボルダリング特有（転落メカニズム）で、室内ボルダリングでの救急受診の最多原因
- 病院・救急データのみの研究では骨折が多くなる傾向（重篤なケースが偏って記録されるため）

**個別の数値**

- PIP関節側副靭帯捻挫：エリートクライマーの **40.5%** に見られた（慢性、手・肘専門の研究1本）
- 神経圧迫症候群：上下肢の症状で受診したスポートクライマーの約 **25%** が該当

**課題として挙げられていること**

- 小児・女性・高齢者を対象とした研究が少ない
- 診断報告の標準化が不十分（「タイムロスあり」「急性のみ」「軽微含む」でバラバラ）
- スピードクライミング単独の怪我データがほぼない

**リサーチとの接続**  
「なぜ続けるのか」を問う前提として、クライミングがいかに怪我と隣り合わせのスポーツかを示す根拠になる。上記のカタログ（指・足首・肩）とも整合する。

### The epidemiology of rock-climbing injuries（2008年）

Jones G, Asghar A, Llewellyn DJ  
*British Journal of Sports Medicine*  
<https://pubmed.ncbi.nlm.nih.gov/18065444/>

**対象・方法**  
英国のクライミング施設11箇所で201名（男性163・女性38、16〜62歳）を対象にした後ろ向き横断研究。

**数値**

| 項目 | 数値 |
|---|---|
| 過去12ヶ月に1件以上怪我したクライマー | 約 **50%** |
| 記録された怪我の総数 | **275件** |
| 急性（転落） | 21名（**10%**） |
| 慢性オーバーユース | 67名（**33%**） |
| 急性（激しい動作起因） | 57名（**28%**） |

**リスク因子**  
登攀頻度・難易度が高いほど怪我リスク増。上肢の蓄積外傷と強く相関。

### Descriptive Epidemiology, Medical Evaluation, and Outcomes of Rock Climbing Injuries（2017年）

McDonald JW, Henrie AM, Teramoto M, Medina E, Willick SE  
*Wilderness & Environmental Medicine*  
<https://pubmed.ncbi.nlm.nih.gov/28755819/>

**対象・方法**  
米国で年4回以上クライミングし、過去24ヶ月に怪我をした18歳以上を対象にウェブ調査（60日間）。708名から1,397件の怪我を収集、975件を分析。

**数値**

| 項目 | 数値 |
|---|---|
| 完治前にクライミング復帰 | **51.1%** |
| 慢性問題に移行 | **44.9%** |
| 怪我前の活動レベルに戻れなかった | **28%** |
| 回復遅延のリスク因子 | 高齢・喫煙・骨折・手術 |

**リサーチとの接続**  
「怪我しても続ける」というテーマに直結する数字。半数以上が完治前に復帰しており、クライミングへの強い動機付けを示唆する。

### National Trends in Rock Climbing Injuries: A 10-Year Epidemiological Analysis of US Emergency Department Data（2025年）

*PMC*  
<https://pmc.ncbi.nlm.nih.gov/articles/PMC12806586/>

**対象・方法**  
米国の救急搬送データ（2014〜2023年）の10年間分析。

**数値**

| 項目 | 数値 |
|---|---|
| 10年間の救急搬送件数（推計） | **47,251件** |
| 骨折 | **26.8%** |
| 捻挫・筋腱損傷 | **20.4%** |
| 軟部組織損傷 | **10.2%** |
| 裂傷 | **8.0%** |
| 下肢の怪我（救急データ） | **50.6%** |
| 上肢の怪我（救急データ） | **26.7%** |
| 転落が原因 | **58.8%** |
| 20フィート超の転落で骨折リスク増 | **+52%** |

**注意点**  
救急搬送データのため重篤例に偏っている（捻挫・軽微な怪我は過小計上）。
