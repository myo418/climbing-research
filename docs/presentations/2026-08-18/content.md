インタビュー 30人程度／岩の観察／登る感覚の記述／クライミングと構図の研究／ワークショップの実施

岩の観察とワークショップは18の答え合わせに1行残すだけで、個別のスライドは作らない。

一本の線:

> 自分が撮った「クライミングの写真」には、**誰も登っていない**。
> 撮っていたのは登攀ではなく、その**前後の時間**だった。
> そして、いちばん怖い時間＝いちばん怪我のリスクが高い時間は、1枚も残っていない。

## 19 活動 06｜インタビュー

**2人目**｜朱さん・クライミング歴 2ヶ月・上海出身

要約せず、[質問項目](/research-methods/interview-questions/)の問いと返ってきた言葉をそのまま対で並べる。
質問は小さく目立たなく、回答を太字で。

| 質問 | 回答 |
|---|---|
| クライミング歴は？ | 「まだ2ヶ月目」 |
| 初めてクライミングに触れたのはいつ、何をきっかけに？ | 「王一博っていう俳優のファンで、その人の趣味がクライミングだったから始めた」 |
| 今は週にどのくらい登っている？ | 「3回が理想。今週は予定があって2回になってしまった」<br>「努力したことが無駄にならないように、何日もクライミングしない日を作りたくなかった」 |
| 上達のペースは気になる？ | 「1ヶ月〜2ヶ月の人が平均でどれくらい上達するのか、自分のペースが遅いのか気になってた」<br>「初めて1ヶ月の友達がV2(4級)登れてたけど、これって早いですよね？？」 |
| 外岩の経験はある？ | 「外岩に興味がある。まだ行ったことはない。半年くらいやって上達したら行きたい」 |
| 高さへの恐怖はある？どれくらい？ | 「リードもやってる。高さは怖くない。ボルダーの着地の方が怖いかも」 |
| 身体は変わった？（筋肉、指、体脂肪、怪我跡など） | 「指が荒れるのは全然気にならない」<br>「擦り傷とか打撲は、そこまで気にしないかな」 |
| 過去にどういう怪我をしたことがある？一番大きな怪我は？ | 「大きな怪我はまだしたことない」 |
| 最近は登れてる？ | 「今は謎の発熱が続くようになって、今しばらくジムに行けてない」 |

左は入口と頻度、右は身体・怪我・現状。質問項目に無理に寄せず、答えに合う問いを立て直したものもある（上達のペース／最近は登れてる）。

**話すこと**（スライドには出さない）: まとめずに読み上げる。入口が「推しの趣味」だったこと、小さい怪我は最初から意識の外にあること、そして**離脱の理由が怪我ではなく体調だった**こと。「怪我が継続と離脱の境界になる」という前提が、1人目でいきなり崩れている

## 20 活動 07｜クライミングと構図の研究（1/3）カメラの決定

写真73枚を、良し悪しではなく**軸**で分けた。まずカメラをどこに置くかの3軸。1行1軸で、左右に作例を並べる。

| 軸 | 一方 | もう一方 |
|---|---|---|
| 寄り ⇔ 引き | 岩のディテールだけ | 河原ごと入れる |
| 見上げる ⇔ 見下ろす | 岩が覆いかぶさる | 場所を俯瞰する |
| 手の寄り ⇔ 全身 | 手とホールドだけ | 人は小さく入る |

## 22 活動 07｜クライミングと構図の研究（3/3）迫力がある・ない

前の2枚で分けた軸が、同じ側に重なったときに「迫力」が出る。左右2分割。

| | 迫力がある | 迫力がない |
|---|---|---|
| 軸 | 寄り／見上げる／手の寄り／露出 高い | 引き／見下ろす／全身／露出 低い |
| 作例 | 自分の写真で一番近いもの。それでも「見上げる」しか振り切れていない | 4つとも反対側。自分の写真のほとんどがこちら |

> **一つ振り切っただけでは、迫力は出ない**

**話すこと**: 20・21が分解で、22が合成。迫力を独立した軸ではなく**複合要因**として置いたのがこの分析の要。プロの写真が迫力を持つのは、複数の軸を同時に振り切っているから

## 23 活動 08｜恐怖との向き合い方

活動06・07と並ぶ**もう一つのリサーチ**。問いの行は置かず、仮説を小さく添えて、あとは淡々とした地の文。右にリードの壁の写真を細長く通す。

**仮説**｜恐怖は、繰り返すうちに慣れて、なくなるのではないか

> 僕は高所が怖い。週2でリードクライミングを続ければ慣れるのか、自分の体で試した。2ヶ月、およそ20日。
> 結果は、克服できなかった。簡単な課題が登れないわけではない。でもボルダーでできる動きが高所ではできず、手汗も止まらなかった。
>
> リードクライミングの講師、心理学や恐怖に詳しい人、書籍にあたる。「慣れ」以外の克服法があるのか。

**話すこと**: 仮説を立てて、自分を被験者にして、20日かけて否定された、という流れをそのまま話す。**否定されたこと自体が成果**。19で朱さんが「高さは怖くない。ボルダーの着地の方が怖いかも」と言っているので、**恐怖の在処は人によって違う**という対比が2枚で立つ

## 25 岩 ＋ クライマー人形の立体

24の new! を具体化するとしたら、という1枚。**岩と人の両方を作る**方針。スケッチ枠は空のまま置いてある。

| | |
|---|---|
| **岩** | 実物大の岩、もしくは岩の形をした造形。素材・スケールは未定 |
| **クライマー** | 登っている人ではなく、見上げる・待つ・触る人 |

> **写真と同じように、らしさ、緊張感の一瞬を切り取る**

**話すこと**: 20〜22で出した「迫力＝寄り × 見上げる × 手の寄り」は、そのまま立体の設計指針になる。どの一瞬を、どの距離から、どの高さで見せるか。平面で撮れなかったものを空間で扱う、という筋で話す

このあとに空のスライドが2枚。「ありがとうございました」は置かない。

## 制作メモ

### 発表までに潰すこと

- **構図の軸は73枚のうち十数枚を実際に見て立てたもの**。残りは未確認。全数を分類し直して「73枚中◯枚が◯側」と数字で言えると強度が変わる
- 「登攀の瞬間が1枚もない」も全数では未確認。1枚でも見つかったら「ほとんどない」に落とす
- **「露出 高い」の作例が手持ちに無い**（21が片側だけ空いている）。ネットから収集して差し込む（プロ／SNSのカットにはこの側が多いはず）。差し込むと「自分の写真だけが片側に寄っている」という主張が視覚的に成立する
- 比較用に、ロープで空中から撮ったカット／完登動画のサムネ／トポの3系統も集められると21・22がさらに効く。出典はキャプションに入れる
