# Blender の人形｜運用メモ

関連: [../../CLAUDE.md](../../CLAUDE.md) / [../../DESIGN.md](../../DESIGN.md)

クライマーを立体にしたもの。インタビュー対象の菅野あいとから始めて、いまは `CHARACTERS` の5人を作り分ける。
[climbers.py](climbers.py) 1本で、体・服・道具・壁・リグ・ポーズ・STL書き出しまで全部作る。
手で作ったメッシュはひとつも無い。`.blend` は出力であって定義元ではないので、
**形を変えるときは必ず `climbers.py` を直してから組み直す。**

## 環境

- Blender 5.2.1 LTS。MCP アドオンのポートは **9877**（既定の9876は higgsfield 拡張と衝突する。
  詳細はグローバルの `~/.claude/CLAUDE.md`）
- Blender 側での実行:

```python
CLIMBERS_STYLES = ["facet"]          # 直立で並べる作り。省略すると blocky だけ
exec(open('/Users/myo/git/climbing-research/scripts/blender/climbers.py').read())
```

スクリプトは**読み込んだ時点で `CLIMBERS_STYLES` のぶんだけ直立を組む**。
ポーズ付きやリグは、そのあと関数を呼ぶ。

```python
build_rig(origin_x=-4.3)                                   # 直立＋骨
build_rigged_pose("climb", origin_x=-7.0, overhang_deg=16) # ポーズ＋壁
build_grid()                                               # 総当たりの格子
export_coll_stl("grid_aito_facet_climb")                    # 1/10 で stl/ へ
```

## 命名規則

### コレクション

**名前は必ず4枠。`<役割>_<人>_<作り>_<ポーズ>`**

```
grid_aito_facet_sit        格子の、菅野あいと、facet、座り
wall_manabu_facet_cutloose 壁の列の、明神、facet、どっかぶり
gear_aito_facet_any        チョーク一式のマスター（ポーズはないので any）
ground_mori_any_any        森秋彩の地面
tmp_ondra_facet_stand      使い捨て。いつ消してもよい
```

| 枠 | 入るもの |
|---|---|
| 役割 | `grid` 格子 / `wall` 壁の列 / `gear` 道具のマスター / `ground` 地面 / `tmp` 使い捨て |
| 人 | `aito` `manabu` `mori` `ondra` `hirayama`（`CHARACTERS` のキー） |
| 作り | `PRESETS` のキー。`facet` `blocky` `bighead_organic` など |
| ポーズ | `POSES` のキー。直立は `stand` |

**人・作り・ポーズは省かない。** aito だけ人の枠を省いていた時期があるが、やめた。
枠が当てはまらないときは `any` で埋める（道具のマスターにポーズはない）。
省くと、名前を見ただけでは何なのか分からないものがシーンに溜まる。

**ポーズ id にアンダースコアを使わない。** 作り id は使ってよい（`bighead_organic`）。
名前は末尾から解く決まりなので、ポーズが1語なら、どこまでが作りかが決まる。

名前を組むのは `make_coll_name(役割, 人, 作り, ポーズ)`、読むのは `parse_coll(名前)`。
`parse_coll()` が `None` を返す名前は規則外。`audit_colls()` が枠ごとに数えて、
規則外のものを並べる。昔の名前は `rename_colls()` が付け直す（組み直しはしない）。

**役割を渡さずに `build()` / `build_rig()` / `build_rigged_pose()` を呼ぶと `tmp_` になる。**
確認のために1体だけ組むときはこれでよい。残したいものには `coll_name=` で役割を付けて呼ぶ。

**`tmp_` は組み終わった時点で、格子から 30m 手前（`TMP_SHIFT`）へ退き、
`tmp` という入れ物の下に入る。** 確認用に組んだものが見比べている列に紛れないようにするため。
退けるのは `park_tmp()`、あとから全部まとめて退けるのは `park_all_tmp()`。

消すのは `drop_tmp()` だが、**退けてあるので消さなくても邪魔にならない。**
確認用に組んだものでも、あとで見たくなることがある。

`tmp` は枠のない名前を許す唯一の例外（`COLL_CONTAINERS`）。中身を持たない入れ物なので、
人も作りもポーズもない。

**同じ名前で組むと、前のコレクションは消える。** `build()` が同名を削除してから作り直すため。
同じ人・同じ作り・同じポーズで2体並べたいときは、役割を変えるか `coll_name` を直接渡す。

**骨（アーマチュア）はコレクションと同じ名前。** `rename_colls()` も一緒に付け替える。

### オブジェクト

部位の名前をそのまま使う。左右は末尾に `_l` / `_r`。

```
leg_l  pants  tee  sleeve_r  arm_l  hand_r  head  hair  hair_back  eye_l
shoe_upper_r  shoe_sole_r  shoe_toe_r  shoe_heel_r  shoe_strap_r  shoe_tab_r
shoe_collar_r  shoe_rim_r  shoe_pivot_r
chalk_bucket  chalk_bucket_rim  chalk_bucket_base  chalk_bag  chalk_bag_logo
wall  wall_pivot  hold_0  hold_bolt_0
```

Blender は同名が来ると `.001` を足す。処理側は `name.split(".")[0]` で素の名前を見ている。

### 骨

| 名前 | 対応 |
|---|---|
| `pelvis` `spine` `chest` `neck` `head` | 体幹。親から順につながる |
| `shoulder.L/R` `upperarm` `forearm` `hand` | 腕 |
| `thigh.L/R` `shin` `foot` | 脚 |
| `f1a/f1b` 〜 `f4a/f4b`、`thumba/thumbb` | 指。`a` が第1関節、`b` が第2関節 |

左右は Blender の慣習どおり `.L` / `.R`（**メッシュ側は小文字 `_l` / `_r`** なので、対応表で変換している）。
指まで入れて **40本**。

## 並べ方

### 格子（作り × ポーズ）

`build_grid()` が総当たりで並べる。**横がポーズ、奥行きが作り。**

- 横の間隔 **2.60m**、奥行きの間隔 **3.40m**
- 間隔は**壁の大きさで決まる**。壁は幅2.4mあるので、これより狭くすると隣の壁と重なって継ぎ目が出る
- 奥行きは座りポーズが1.2m使うぶんを見ている
- 壁は人形の**手前（−y）**に立つので、真正面から見ると手前の列が奥を隠す。
  形だけ見比べたいときは `build_grid(wall=False)`

### 壁パターンの帯

被り角ちがいの3体は、格子から離して**右側（+x）に一列**に置く。

| x | コレクション | 被り |
|---|---|---|
| 10.2 | `wall_aito_facet_traverse` | 0°（垂壁） |
| 14.2 | `wall_aito_facet_precatch` | 16°（薄被り） |
| 18.2 | `wall_aito_facet_cutloose` | 38°（どっかぶり） |

間隔 **4.0m**。壁が傾くと足元より上が手前にせり出すので、格子の2.6mでは足りない。

### 位置をずらす

コレクションごと動かすときは、**親のいないオブジェクトだけ**動かす。
靴や指は空オブジェクトや骨にぶら下がっているので、子まで動かすと二重にずれる。
`shift_y()` がこれをやっている。

## パターン（作り）の基準

`PRESETS` が定義元。`style`（面の作り）／`head_scale`（頭の倍率）／`eyes`／`hands` の掛け合わせ。

| 名前 | 面の作り | 特徴 |
|---|---|---|
| `blocky` | 箱の積み上げ。部位ごとに1色 | いちばん素朴。手は筒1本 |
| `blocky_fingers` | 同上 | 指まで作る |
| `facet` | 断面をつないだ体＋三角ポリゴン | **本命。** 面ごとに濃さを振る |
| `organic` | 同じ材質の部品を結合し、ボクセルで溶かす | 継ぎ目の無い一体 |
| `bighead` | facet の体＋頭1.55倍 | 顎を軸に拡大するので体はそのまま |
| `bighead_organic` | organic の体＋頭1.55倍 | |
| `noeyes` | facet から目を外す | 顔を描かない線画側に寄せた版 |

### 面の作りの中身

- **blocky** — `box()` と `limb()` で箱と角柱を積む。フラットシェード
- **facet** — `loft()` / `chain_mesh()` で断面をつなぎ、`facetize()` が三角に割って
  **面ごとの色を頂点カラーに焼く**。材質は1つで足りる（色はメッシュ側にある）。
  色の振れ幅は 0.74〜1.22 倍。細かく割るとノイズに見えるので、粗い面のまま三角にしている
- **organic** — 同じ材質の部品を結合し、ボクセルで溶かしてから均す。
  体・服は voxel 0.019、**道具は 0.006〜0.009**（粗いとシューズの形が消える）

## ポーズの基準

`POSES` が定義元。**関節の位置を世界座標で書くだけ。** 体の前は −y、壁は −y 側に立つ。

| 名前 | 中身 | 壁 |
|---|---|---|
| `natural` | 自然な直立 | なし |
| `sit` | マットに座って壁を見上げる | なし |
| `hang` | 両手でぶら下がる | あり |
| `climb` | 片手を上へ、片足をステップアップ | あり |
| `reach` | 次のホールドへ手を伸ばして掴んだ状態 | あり |
| `traverse` | 横へ移動する途中。右手右足を横へ送る | あり |
| `precatch` | 取る直前。**右手はまだ開いていて届いていない** | あり |
| `cutloose` | 両手で保持、**足が切れて振られている** | あり |

### ポーズが持てる指定

| キー | 意味 |
|---|---|
| `pelvis` `waist` `chest` `neck` `chin` `crown` | 体幹の関節 |
| `shoulder` `elbow` `wrist` `tip` `hip` `knee` `ankle` | 左右のある関節。`dict(r=…, l=…)` |
| `shoe_rot` | 靴の向き（左右別） |
| `grip` | 指の曲げ。`(第1関節, 第2関節)` の角度。`{"R": …, "L": …}` で手ごとに変えられる |
| `wall_y` | 壁を立てる位置。無ければ壁を作らず、代わりに床へ下ろす |
| `contacts_only` | ホールドを置く接点を選ぶ。足が切れているポーズで使う |
| `hold_offset` | ホールドを壁沿いにずらす。「届いていない」表現に使う |
| `tilt_pivot` | 被らせるときの回転軸。既定は下の足。足が壁に無いなら掴んでいる手 |
| `toe_offset` | 爪先の向き |

### 被り角

`build_rigged_pose(..., overhang_deg=38)` の数値ひとつ。壁とポーズの両方に効く。

**壁だけ傾けても被り壁には見えない。** 体が壁に対して直立したままになるため、
`tilt_pose()` がポーズ全体を同じ角度ぶん寝かせる。
ただし壁と完全に平行にすると脚が水平に突き出るので、**脚だけ股関節を軸に被り角の55%ぶん重力方向へ戻す**。

## 壁とホールド

**壁の位置は接点から決める。** 骨の長さは変えられないので、関節の座標どおりの場所に手足は届かない。
そこで先にポーズを付け、**実際に手足が来た位置**を測ってから壁を立てる。

- 手の接点 = `hand` 骨の先
- 足の接点 = **靴のつま先の実位置**（骨の先は靴の中にあるので、そこだと爪先が浮く）
- 壁面はどの接点にも当たらない位置に置き、**ホールドの奥行きで距離を埋める**（48〜78mm）
- 手のホールドは中心を接点に合わせ、足は**天面を爪先の高さ**に合わせる

ホールドは4枚の断面を重ねた不規則な多面体。輪郭を7角形＋乱数で崩してある（種は番号から作るので毎回同じ形）。
手のホールドは前へ行くほど輪郭が上へずれて、**下に指がかかる縁（インカット30mm）** ができる。足は6mmでほぼ平ら。

壁とホールドは `wall_pivot` という空オブジェクトにぶら下げて、まとめて傾けている。

## リグ

### 結合のしかた

| 部位 | 方法 |
|---|---|
| 脚・パンツ・腕・袖・Tシャツ・首 | **距離ウェイト**（`skin_by_distance`） |
| 頭・髪・靴・目 | 骨に直付け |
| 手（手のひら＋指5本の1メッシュ） | 範囲ごとに距離ウェイト |

**自動ウェイト（bone heat）は使わない。** 体が別々のメッシュに分かれているので、
短パンやTシャツが遠くの骨に引っ張られて板状に伸びる。
代わりに**メッシュごとに効かせる骨を明示的に列挙**し、頂点ごとに近い骨2本へ距離の逆数（4乗）で振る。

- パンツに許しているのは `pelvis` `thigh` `shin` **だけ**。腕の骨は候補に入らない
- 脚とパンツは**骨の顔ぶれを揃える**。違うと腿の付け根で別々に回って脚が突き出る
- パンツは1メッシュだが、**腰・左脚・右脚のどの頂点範囲がどの部分か**を覚えさせて、
  範囲ごとに別の骨を割り当てる（`skin_parts`）。左脚に右脚の骨を入れないので股の間が伸びない

### 関節が痩せないようにする

アーマチュア修飾子の **Preserve Volume**（デュアルクォータニオン）を有効にする。
線形ブレンドは折れ目で体積が落ちる（キャンディーラッパー）。

### 骨の回し方

**基本姿勢の向きから目標の向きへの最短回転**を使う。

```python
swing = (inherited @ rest_dir).rotation_difference(target_dir)
aim = swing @ inherited @ rest_q
```

ロールを自分で決めようとすると、足首（前を向く骨）や大きく回した腕でねじれる。
最短回転にはねじれが入らない。親の動きを先に受け継いでから振ることで、軸回転の反転も起きない。

### 基本姿勢

- **指はまっすぐ開いておく。** 曲げた形を素にすると伸ばせない。握りは `grip` でポーズ側から指定する
- 腕は垂直から **15°** 開く。狭いと手が短パンにめり込む

## インスタンス（同じものを1つにまとめる）

3種類ある。目的が違う。

### 1. ポーズ間で体を共有する — `link_poses()`

同じ作りの行のなかで、**直立のメッシュをほかのポーズにも使わせる**。
どのポーズも同じ立ち姿から組んで骨で曲げているだけなので、体は1つで足りる。
残る違いは骨の回転だけになり、**直立を1つ直せばその行のポーズ全部が変わる**。

ウェイトはメッシュに入っていて、ワールド座標から計算している。
列ごとに x が違うと最下位桁が揺れて、中身が同じはずのメッシュが別物になる。
それを揃えるのがこの処理なので、**`link_same_meshes()` より先に走らせる。**

### 2. 同じ形のメッシュを1つにする — `link_same_meshes()`

中身が同じメッシュを1つのデータにまとめ、全員がそれを参照する。
靴やチョークのように、どの体でも同じ形のものがこれで1つになる。
まとめたあとは、**1つを編集モードで直すと同じ形のもの全部が変わる。**

位置の違いはメッシュではなくオブジェクトの `location` 側に入っているので、共有しても並びは崩れない。
修飾子（organic の remesh など）もオブジェクト側に残るので、organic の行だけ溶けたまま保てる。

### 3. チョーク一式の参照 — `gear_instances()`

チョークは材質の違う6部品でできていて、organic ではバケツと袋にだけ voxel の修飾子が乗る。
**1メッシュに結合すると修飾子はオブジェクト単位なので、縁も書き文字もロゴも溶けてしまう。**
そこで結合せず、6つのまま `gear_<人>_<作り>_any` に置き、各体にはそれを参照する空オブジェクトを1つだけ置く。

**マスターはシーンに繋がない。** 繋ぐと原点にもう1セット立つ。参照している空オブジェクトがあるかぎり消えない。

## 人（キャラクター）

`CHARACTERS` が定義元。身長・細さ・服の色・髪・チョークの持ち方を持つ。

| 名前 | 中身 |
|---|---|
| `aito` | 身長1.72m。黒Tシャツ／ピンクの短パン／赤い靴／置きバケツ |
| `manabu` | 身長1.70m・細さ0.94。黄緑のTシャツ／濃緑の長ズボン／水色の靴／腰のチョークバッグ／天然パーマ |

身長と細さは**組み上がった体を縮める**（`shape_body`）。
骨も同じ倍率で縮むので、ポーズの関節位置も `scaled_pose()` で合わせる。
合わせないと腕の開きや足の幅が型のままになる。

## STL 書き出し

```python
export_coll_stl("grid_aito_facet_climb")                 # 既定 = 1/10。
                                                        # 名前から stl/aito_facet_climb.stl
export_stl("grid_aito_facet_climb", "<出力先>.stl", scale=1000)  # 実寸・置き場を指定
```

**ファイル名は `<人>_<作り>_<ポーズ>.stl`。** 役割は付けない（出すのは人形だけなので、
役割の枠に意味がない）。`export_coll_stl()` がコレクション名を読んでこの名前を作る。

**STL は単位を持たない。** 入っているのはただの数値で、読む側が mm とみなすだけ。
既定の倍率100は「1m を 100 と書く」＝ 1/10 スケール。実寸なら1000。

- リグの変形を適用した結果を出すので、ポーズが乗った形が落ちる
- 壁・ホールド・チョーク・地面は除外。靴は含む
- **色は入らない**

### 印刷するときに効いてくる寸法（1/10）

| 部位 | 寸法 |
|---|---|
| 全高 | 174.5mm（登りポーズは202mm。腕を上げているぶん） |
| 指の太さ | 約1.8mm |
| 履き口の縁 | 約0.4mm |

指と履き口の縁が限界域。FDMだと縁は潰れる。光造形なら両方出る。

## つまずいた点

| 症状 | 原因 | 対処 |
|---|---|---|
| 確認用に組んだものが格子に紛れて溜まる | 名前に役割がなく、置き場も原点のまま | 役割を4枠目に入れ、`tmp_` は組み終わりに y−30m へ退ける |
| 短パンやTシャツが板状に伸びる | 自動ウェイトが遠くの骨を拾う | メッシュごとに骨を列挙して距離ウェイト |
| 足首・肘がねじれる | ロールを骨ごとに決めていた | 最短回転にする |
| 肩が尖る／切れ目が出る | 袖が上腕の骨に丸乗り | 胴と腕の間で混ぜる |
| 脚が短パンから出る | 脚と短パンで骨の顔ぶれが違う | 揃える＋短パンを太らせる |
| 関節が細る | 線形ブレンドの体積減 | Preserve Volume |
| **STL で靴が消える** | 面が裏返っていた（レンダーは裏面も描くので気づけない） | 生成時に法線を外向きへ揃える |
| 足が壁から浮く | 骨の長さが固定で届かない | 壁の位置を接点から決め、ホールドの奥行きで埋める |
| 尻が平ら | 断面が前後対称の楕円 | 断面の奥行きを前後で分ける（`(cx, cy, z, rx, ry_back, ry_front)`） |
| チョークが原点にもう1セット立つ | マスターをシーンに繋いでいた | 繋がない |
| 同名のコレクションで前の1体が消える | `build()` が同名を削除する | `coll_name` で名前を分ける |
